=====================================================================
 gateway-server: every route and role rule as a ready-to-use curl
=====================================================================

 HOW TO USE
 - Postman: Import -> Raw text -> paste one curl -> Continue -> Import.
   (or paste the curl straight into Postman's URL bar)
 - Terminal: paste into Git Bash. (Not into CMD or PowerShell: they do not
   understand the ' quotes.)
 - To run all of them at once with PASS / FAIL:  bash curl/run-all.sh

 This is how the frontend talks to the backend: everything goes to the
 gateway on http://localhost:5002. The gateway checks the token and the
 role, then sends the request to the right service (found in Eureka).

 Needs running: Eureka (8070), Keycloak (8080), gateway (5002) and the
 services behind it: user 5009, salon 5008, category 5010,
 service-offering 5003, booking 5001, payment 5004, notification 5007.

 Everything is filled in. The only thing you replace is:
   PASTE_CUSTOMER_TOKEN  -> the "jwt" from step 2
   PASTE_OWNER_TOKEN     -> the "jwt" from step 3
   PASTE_ADMIN_TOKEN     -> the "access_token" from step 4
   PASTE_SALON_ID        -> the "id" from step 9
   PASTE_CATEGORY_ID     -> the "id" from step 11
   PASTE_SERVICE_ID      -> the "id" from step 12
   PASTE_CUSTOMER_ID     -> the "id" from step 5
 Copy only the value, without the quotes.

 DATES: a booking must be in the future, 09:00-20:00. Step 14 uses
 2026-12-01; change it to any future day if that date has passed.
 If sign up says 409 "already exists", change the email and username.


=====================================================================
 OPEN ROUTES (no token)
=====================================================================

---------------------------------------------------------------------
 1. Gateway health                                      expect 200
---------------------------------------------------------------------
curl --location --request GET 'http://localhost:5002/actuator/health'


---------------------------------------------------------------------
 2. Sign up a customer, through the gateway             expect 200
    -> user-service. Answer has "jwt" (= PASTE_CUSTOMER_TOKEN)
---------------------------------------------------------------------
curl --location --request POST 'http://localhost:5002/auth/signup' \
--header 'Content-Type: application/json' \
--data '{
    "email": "gwcustomer1@example.com",
    "username": "gwcustomer1",
    "password": "Passw0rd-123",
    "fullName": "Gateway Customer",
    "role": "CUSTOMER"
}'


---------------------------------------------------------------------
 3. Sign up a salon owner, through the gateway          expect 200
    Answer has "jwt" (= PASTE_OWNER_TOKEN)
---------------------------------------------------------------------
curl --location --request POST 'http://localhost:5002/auth/signup' \
--header 'Content-Type: application/json' \
--data '{
    "email": "gwowner1@example.com",
    "username": "gwowner1",
    "password": "Passw0rd-123",
    "fullName": "Gateway Owner",
    "role": "SALON_OWNER"
}'


---------------------------------------------------------------------
 4. Admin token, straight from Keycloak                 expect 200
    Answer has "access_token" (= PASTE_ADMIN_TOKEN)
---------------------------------------------------------------------
curl --location --request POST 'http://localhost:8080/realms/master/protocol/openid-connect/token' \
--data-urlencode 'client_id=salon-booking-client' \
--data-urlencode 'client_secret=<KEYCLOAK_CLIENT_SECRET>' \
--data-urlencode 'grant_type=password' \
--data-urlencode 'username=<KEYCLOAK_ADMIN_USERNAME>' \
--data-urlencode 'password=<KEYCLOAK_ADMIN_PASSWORD>'
